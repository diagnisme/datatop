## Optimisation

Chaque page a :
- Un titre < 60 caractères
- Une meta description (160 caractères)
- Un seul H1
- Des H2/H3 hiérarchisés
- Minimum 1000 mots

## Vérifier sur Google Search Console

1. Va sur https://search.google.com/search-console/
2. Ajoute le site
3. Soumet `sitemap.xml`
4. Vérifie que les pages sont indexées

## Améliorer le ranking

- Crée du contenu régulièrement
- Ajoute des liens internes entre pages
- Vérifie les mots-clés qui ramènent du traffic
- Réponds aux questions courantes en 40-60 mots

## Exemple de contenu optimisé

```html
<h2>Qu'est-ce que la Data science ?</h2>
<p>La Data science analyse les données pour extraire des insights. Elle combine mathématiques, statistiques et informatique pour aider les entreprises à prendre meilleures décisions.</p>
```

Google aime cette structure pour les featured snippets.
